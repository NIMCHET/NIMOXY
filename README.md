# 🐸 NIMOXY — Global DNS Optimizer for Windows

NIMOXY is an advanced Windows DNS optimization and benchmarking application designed to discover, test, rank, verify, and intelligently manage public DNS resolvers.

It is built around one core idea:

> Don't blindly choose a famous DNS server. Measure real resolver performance, compare multiple candidates, verify the result, and only then use it.

NIMOXY can discover a large and continuously changing public DNS catalogue, perform fast resolver probing, run deeper multi-round benchmarks, calculate latency/P95/jitter/loss metrics, evaluate gaming-service coverage, rank candidates, apply a selected resolver to Windows, verify the change, and optionally let Auto Pilot monitor the current resolver and switch only when a meaningfully better verified candidate is available.

NIMOXY is designed for gamers, competitive FPS players, power users, network troubleshooting, and anyone who wants evidence-based DNS selection instead of guessing.
